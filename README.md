# 家計簿サービス（kakeibo-service）

クレジットカードの利用通知メール（Gmail）を自動で読み取り、Googleスプレッドシートに記録して、
LINEで毎日の決算や高額利用のアラートを届ける家計簿サービスです。

利用者に必要なのは、**LINEとGoogleアカウントだけ**です。パソコンへのインストールは不要で、
スマートフォンだけで使い始められます。

## 使い方

1. LINEで「日次決算Bot」を友だち追加する
2. Botから届いたリンクを開き、「Googleで連携する」を押して許可する
   （「Googleはこのアプリを確認していません」と表示されたら、「詳細」→「（アプリ名）に移動」で進む）
3. 自分のGoogleドライブに家計簿のスプレッドシートが作られ、30分以内にLINEで準備完了のお知らせが届く
4. スプレッドシートの「送信元リスト」「設定」「予算計画」を確認・入力する

設定（締め日・通知の時刻など）は、すべてスプレッドシートで変更できます。
使うのをやめるときは、LINEで「**連携解除**」と送ってください。

## できること

- カード利用通知メールから、日時・店舗名・金額を読み取ってスプレッドシートに記録
- 店舗名からカテゴリ（食費・交通費など）を自動で判定
- 毎日決まった時刻に、締め期間の累計と予算との比較をLINEで通知（日次決算）
- 週に1回、カテゴリ別の内訳をLINEで通知（週次決算）
- 高額な利用があったときに、すぐにLINEでお知らせ
- 月末のサブスク棚卸し、締め日の振り返りコメント、年末の年間サマリー

## プライバシーポリシー（データの扱いについて）

**アクセスするデータ**

- **Gmail**：「送信元リスト」に登録したカード会社からの利用通知メールだけを検索して読み取ります。
  処理済みの目印としてラベルを付けます。それ以外のメールを読み取ったり、保存したりすることはありません。
- **Googleドライブ**：このサービスが作成した家計簿のスプレッドシートだけを読み書きします
  （あなたの他のファイルには、アクセスする権限自体がありません）。

**データの保存場所**

- 取引の記録は、**あなた自身のGoogleドライブ**の家計簿スプレッドシートにだけ保存されます。
  運営者の手元に、メールの内容や取引の記録を保存することはありません。
- Googleへのアクセス許可（認証情報）は、運営者が管理する非公開の保管場所（Google Apps Script）にだけ保存されます。
  処理のたびに、そこから1時間で使えなくなる一時的な鍵だけを取り出して使います。

**処理の流れ**

- 30分おきに、GitHub Actions上でこのリポジトリのプログラムが実行され、利用者ごとに処理を行います。
  実行ログには、金額・店舗名・メールアドレスなどの個人情報は表示されません。

**外部サービスへの送信**

- **LINE**：通知の内容（金額・店舗名など）を、日次決算Bot経由であなたのLINEに送ります。
- **Anthropic（Claude）**：店舗名のカテゴリ判定のために店舗名を、振り返りコメント作成のために集計結果を送信します。
- **為替レートAPI（open.er-api.com）**：外貨建ての利用があった場合に、通貨コード（USDなど）だけを送ってレートを取得します。

**連携の解除とデータの削除**

- LINEで「連携解除」と送るか、日次決算Botをブロックすると、保管していた認証情報を削除し、
  Googleへのアクセス許可も取り消します。家計簿のスプレッドシートは、あなたのGoogleドライブに残ります。
- Googleアカウントの「[サードパーティのアプリとサービス](https://myaccount.google.com/connections)」からも、
  いつでもアクセス許可を取り消せます。

## 構成（運営者向け）

```
LINE（日次決算Bot）⇄ 中継役（Google Apps Script）：友だち追加の受付・連携リンクの発行・認証情報の保管
連携ページ（GitHub Pages：kakeibo-auth）→ 中継役：Googleの許可コードの受け渡し
このリポジトリ（GitHub Actions・30分おき）
  src/runner.py   … 中継役から利用者の一覧と一時的な鍵を受け取り、1人ずつ src/user_run.py を実行
  src/user_run.py … 利用者1人分の処理（初回は家計簿のシートを作成 → src/main.py の処理）
```
