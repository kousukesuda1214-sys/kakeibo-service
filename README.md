# 家計簿サービス（kakeibo-service）

クレジットカードの利用通知メール（Gmail）を自動で読み取り、Googleスプレッドシートに記録して、
LINEで毎日の決算や高額利用のアラートを届ける家計簿サービスです。

利用者に必要なのは、**LINEとGoogleアカウントだけ**です。パソコンへのインストールは不要で、
スマートフォンだけで使い始められます。

## 使い方

1. LINEで「日次決算Bot」を友だち追加する
2. Botから届いたリンクを開き、「Googleで連携する」を押して許可する
   （「Googleはこのアプリを確認していません」と表示されたら、「詳細」→「（アプリ名）に移動」で進む）
3. 自分のGoogleドライブに家計簿のスプレッドシートが作られ、2〜3分（遅くとも30分以内）でLINEに準備完了のお知らせが届く
4. スプレッドシートの「送信元リスト」「設定」「予算計画」を確認・入力する

設定（締め日・通知の時刻など）は、すべてスプレッドシートで変更できます。
使うのをやめるときは、LINEのメニューの「**連携・解除**」から解除してください。
同じGoogleアカウントで連携し直すと、前の家計簿の続きから使えます。

## できること

- カード利用通知メールから、日時・店舗名・金額を読み取ってスプレッドシートに記録
- 店舗名からカテゴリ（食費・交通費など）を自動で判定
- 毎日決まった時刻に、締め期間の累計と予算との比較をLINEで通知（日次決算）
- 週に1回、カテゴリ別の内訳をLINEで通知（週次決算）
- 高額な利用があったときに、すぐにLINEでお知らせ
- 月末のサブスク棚卸し、締め日の振り返りコメント、年末の年間サマリー

## プライバシーポリシー（データの扱いについて）

**[プライバシーポリシーはこちら（docs/PRIVACY.md）](docs/PRIVACY.md)**

かんたんにまとめると：

- Gmailは、登録したカード会社などの利用通知メールだけを読みます。Googleドライブは、このサービスが作った家計簿だけを読み書きします
- 取引の記録は、**あなた自身のGoogleドライブ**の家計簿にだけ保存されます
- 運営者の保管場所には、サービスを動かすのに必要なもの（認証情報・家計簿のファイルID・LINEのメニュー用の最新の合計額など）だけを置き、連携を解除すると削除します
- 同じGoogleアカウントで連携し直したときに前の家計簿を使えるよう、解除後も「どの家計簿を使っていたか」の控えだけを約13か月残します（認証情報は残しません）

## 構成（運営者向け）

```
LINE（日次決算Bot）⇄ 中継役（Google Apps Script）：友だち追加の受付・連携リンクの発行・認証情報の保管
連携ページ（GitHub Pages：kakeibo-auth）→ 中継役：Googleの許可コードの受け渡し
このリポジトリ（GitHub Actions・30分おき）
  src/runner.py   … 中継役から利用者の一覧と一時的な鍵を受け取り、1人ずつ src/user_run.py を実行
  src/user_run.py … 利用者1人分の処理（初回は家計簿のシートを作成 → src/main.py の処理）
```
