# プライバシーポリシー（家計簿サービス）

最終更新：2026年9月29日

家計簿サービス（LINE公式アカウント「日次決算Bot」と、このリポジトリのプログラム）は、
クレジットカードの利用通知メールを読み取って、利用者ご本人のGoogleスプレッドシートに記録し、
LINEで決算をお知らせするサービスです。運営者は個人（GitHub：[kousukesuda1214-sys](https://github.com/kousukesuda1214-sys)）で、家族・知人向けに提供しています。

## 1. アクセスするデータ

- **Gmail**（権限：`gmail.modify`）
  「送信元リスト」に登録したカード会社などからの利用通知メールだけを検索して読み取ります。
  読み取ったメールには、処理済みの目印としてラベル（`家計簿サービス_処理済み`）を付けます。
  それ以外のメールを読み取ったり、保存したり、送信・削除したりすることはありません。
- **Googleドライブ**（権限：`drive.file`）
  このサービスが作成した家計簿のスプレッドシートだけを読み書きします。
  あなたの他のファイルには、アクセスする権限自体がありません。
- **LINE**
  LINEのユーザーID（お知らせの送り先として）と、メニューのボタン操作・メッセージの内容（返信を作るため）を使います。
  プロフィール名・写真・友だちの情報は使いません。

## 2. データの保存場所

**あなたのGoogleドライブ**
取引の記録（日時・店舗名・金額・カテゴリ）と設定は、あなた自身の家計簿スプレッドシートにだけ保存されます。

**運営者が管理する非公開の保管場所**（Google Apps Script のスクリプトプロパティ）
サービスを動かすために、次のものだけを保管します。

| 保管するもの | 目的 | 消えるとき |
|---|---|---|
| LINEのユーザーID、Googleのメールアドレス、家計簿のファイルID、連携した日 | 誰の家計簿をどこに記録するかを知るため | 連携を解除したとき |
| Googleへのアクセス許可（認証情報） | 30分おきの自動記録のため。処理のたびに、ここから1時間で使えなくなる一時的な鍵だけを取り出して使います | 連携を解除したとき |
| 最新の数字（締め期間の合計・今日の利用額・予算・カテゴリ別の金額・設定の表示） | LINEのメニューのボタンにすぐ返信するため。店舗名や個々の取引は含みません | 連携を解除したとき |
| 連携を解除した人の家計簿の控え（メールアドレスを元に戻せない形に変換したもの、家計簿のファイルID、最初に連携した日） | 同じGoogleアカウントで連携し直したときに、前の家計簿の続きから使えるようにするため。認証情報は含みません | 連携し直したとき、または解除から約13か月後 |

運営者が、メールの本文や取引の一覧を手元に保存することはありません。

## 3. 処理の流れ

30分おきに、GitHub Actions 上でこのリポジトリのプログラムが実行され、利用者ごとに処理を行います。
このリポジトリは公開されているため実行ログは誰でも見られますが、ログには金額・店舗名・メールアドレス・LINEのIDなどの
個人情報を表示しないようにしています（「利用者#1：成功」のような結果と、エラーの種類だけを表示します）。

## 4. 外部サービスへの送信

- **LINE**：お知らせの内容（金額・店舗名など）を、日次決算Bot経由であなたのLINEに送ります。
- **Anthropic（Claude）**：店舗名のカテゴリ判定のために店舗名を、振り返りコメント作成のために集計結果を送信します。
  Anthropic のAPIに送ったデータは、Anthropic のポリシーに従って扱われます（AIの学習には使われません）。
- **為替レートAPI（open.er-api.com）**：外貨建ての利用があった場合に、通貨コード（USDなど）だけを送ってレートを取得します。
- **GitHub**：処理のプログラムを実行する場所です。GitHub に個人情報を保存することはありません。

データを販売したり、広告に使ったりすることはありません。

## 5. 連携の解除とデータの削除

- LINEで「連携・解除」のボタンから解除するか、日次決算Botをブロックすると、保管していた認証情報・最新の数字を削除し、
  Googleへのアクセス許可も取り消します。家計簿のスプレッドシートは、あなたのGoogleドライブに残ります（不要なら削除してください）。
- Googleアカウントの「[サードパーティのアプリとサービス](https://myaccount.google.com/connections)」からも、いつでもアクセス許可を取り消せます。
- 上の表の「連携を解除した人の家計簿の控え」もすぐに消したい場合や、その他のお問い合わせは、運営者に直接ご連絡ください。

## 6. このポリシーの変更

内容を変えるときは、このページを更新し、上の「最終更新」の日付を変えます。
